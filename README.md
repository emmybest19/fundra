# Fundra

A production-style fintech backend built with Node.js, TypeScript, Express, PostgreSQL and Prisma. It covers authentication, KYC, digital wallets, a double-entry ledger, peer-to-peer transfers, payments, webhooks, notifications, audit logging and an admin API.

> Work in progress. Built incrementally, one module at a time.
